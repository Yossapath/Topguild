สถานะฐานข้อมูล: LocalStorage (โหมดส่วนตัว/ยังไม่ได้เชื่อม Firebase)
Guild Data Center

ระบบข้อมูลกิลด์

รายชื่อสมาชิกแยกตามอาชีพ และการจัดทีมลงสนามหลัก / สนามรอง (ซิงค์ข้อมูล Real-time)
🔍
รายชื่อที่ยังไม่ได้จัดทีม เลือก "อาชีพ" ในแถวก่อน แล้วค่อยเลือก "ชื่อ" จากรายชื่ออาชีพนั้น

🔥 ตั้งค่าการเชื่อมต่อ Firebase Cloud Database

เมื่อตั้งค่า Firebase Config แล้ว ข้อมูลสมาชิกและการจัดทีมจะถูกบันทึกขึ้น Cloud และซิงค์แบบ Real-time ให้ผู้ใช้อื่นๆ ในกิลด์เห็นทันที! (หากเว้นว่างไว้ ระบบจะใช้ LocalStorage ในเครื่องของคุณ)

📦 จัดการข้อมูล (Data Management)

คุณสามารถนำเข้า/ส่งออกข้อมูล หรือรีเซ็ตข้อมูลกิลด์กลับเป็นค่าเริ่มต้นได้ที่นี่

ข้อมูลกิลด์ · อัปเดตล่าสุดและจัดการผ่านระบบ Firebase / LocalStorage

เพิ่มสมาชิกใหม่

⚡ กำหนดรายชื่อสนามหลัก (60 คน) เพื่อจัดทีม

ระบุหรือวางรายชื่อสมาชิก 60 คนสำหรับสนามหลัก (บรรทัดละ 1 ชื่อ) ระบบจะจัดสนามหลักตามรายชื่อนี้ และนำสมาชิกคนที่เหลือทั้งหมดไปจัดลงสนามรองตามกฎกิลด์ให้อัตโนมัติ

✨ คำแนะนำ: จำนวนที่ดึงอัตโนมัติ จะคัดเลือกมี Priest 12 คนสำหรับสนามหลักให้อัตโนมัติ
ตรวจพบรายชื่อ: 0 / 60 คน
